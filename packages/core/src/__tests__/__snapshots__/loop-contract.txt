Tools you may call, one per "tool" step. Send {"kind":"tool","name":<name>,"args":{...}}:
- read_file: Read one file inside the project.
    path: string. Path relative to the project root.
- search: Search the project.
    query: string. Words to look for.
    scope?: "code" | "specs" | "memory". Defaults to code.
- context: Get a code outline for a path, a query, or a symbol.
    path?: string.
    query?: string.
    symbol?: string.
- run_check: Run one allowed check at the current commit. The result shows an evidence path.
    run: string. The exact command string from the allowlist.
- write_file: Write one file inside the project. You cannot write the accepted-decisions file or anything under .sdd.
    path: string. Path relative to the project root.
    contents: string. The full new contents of the file.
- commit: Commit paths on your own branch. The message is one line.
    message: string. A one-line commit message.
    paths: string[]. Files to commit, relative to the project root.
A person does these: push, pull request, merge, tag, deploy. A call to them is refused.
run_check accepts only these exact commands:
    pnpm test
    pnpm lint

Reply with exactly one JSON object. No prose, no code fences. Start with { and end with }. Send one step per reply. The kind of the step is one of:
- {"kind": "plan", "items": string[]}  Write down the steps you will take. Plan before you act.
- {"kind": "tool", "name": string, "args"?: any}  Call one tool from the tool list. Its result comes back on the next turn.
- {"kind": "check", "claim": string, "evidence"?: string[]}  State a claim about the work. A claim that something passes needs evidence.
- {"kind": "ask", "question": string, "options": string[], "suggest"?: string}  Stop and ask the person one question. Use it when you are blocked or unsure.
- {"kind": "done", "summary": string, "outputs": string[], "evidence"?: string[]}  Finish the work. List the files you produced in outputs.
Keys ending in ? are optional. A reply that does not match is refused.
Valid: {"kind":"plan","items":["Read the spec","Add the retry","Run the tests"]}
Valid: {"kind":"tool","name":"read_file","args":{"path":"changes/refund-retry/spec.md"}}
Valid: {"kind":"check","claim":"Refund calls retry 3 times and the tests pass.","evidence":["changes/refund-retry/evidence/0a1b2c3.json"]}
Valid: {"kind":"ask","question":"Should a retry also cover timeouts?","options":["yes","no"],"suggest":"yes"}
Valid: {"kind":"done","summary":"Refund calls retry 3 times, 2 seconds apart. Tests pass.","outputs":["src/refund/client.ts"],"evidence":["changes/refund-retry/evidence/0a1b2c3.json"]}
Invalid: {"kind":"read_file","path":"changes/refund-retry/spec.md"}
Why it is invalid: kind must be plan, tool, check, ask or done. A tool call is {"kind":"tool","name":"read_file","args":{...}}.
