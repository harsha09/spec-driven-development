# Output contract
Reply with exactly one JSON object. No prose, no code fences. Start with { and end with }. Shape:
- {"type": "post" | "objection" | "agree" | "block" | "decision", "text": string, "cite"?: string}
    type: post, objection, agree, block, or decision.
    text: One line.
    cite?: What you point at. An objection needs one.
Keys ending in ? are optional. A reply that does not match is refused.
An objection needs a cite.
Valid: {"type":"objection","text":"CHK-004: the retry limit for a failed payment is missing.","cite":"CHK-004"}
Invalid: {"type":"shrug","text":"Not sure."}
Why it is invalid: type must be post, objection, agree, block or decision.
