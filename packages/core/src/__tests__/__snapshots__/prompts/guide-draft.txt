# Output contract
Reply with exactly one JSON object. No prose, no code fences. Start with { and end with }. Shape:
- {"text": string, "parts"?: {"heading": string, "text": string}[]}
    text: The whole draft, or "Question: ..." when one fact is missing.
    parts?: The draft split under the listed headings.
Keys ending in ? are optional. A reply that does not match is refused.
If one fact is missing, set text to "Question: ..." and leave parts out.
Otherwise put the whole draft in text and split it into parts, one entry per heading.
Use only these headings, spelled exactly:
- Goals
- Non-goals
Valid: {"text":"Draft for the todo list.","parts":[{"heading":"Goals","text":"People add, finish, and remove todo items."}]}
Invalid: {"text":"Draft for the todo list.","parts":"Goals"}
Why it is invalid: parts must be a list of {heading, text} objects.
