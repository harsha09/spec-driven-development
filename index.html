sddSpec-Driven Development for AI coding agents

Your AI writes code fast. The reasons disappear into chat. sdd is a local CLI that keeps short plans and notes next to your code—so you, your team, and the agent stay aligned.

Start in 10 minutes
npm package

Simple commands

setup → go, or new → fill a short file → next → complete. You always know where you are with sdd status.

Roles with a duty

Planner, architect, and builder each follow the stages of the workflow you name. sdd go asks their questions, and with a role model it hands the next stage to the next role. You still decide.

As light or as heavy as you need

Tiny fix? Three steps. Real feature? A bit more. New product or big platform work? Longer path. Same tool.

Works with your AI

Pick Copilot, Grok, Claude, Ollama, or Kilo once. Use any editor. No marketplace extension required.

Try it in three steps ​

Install Structured Vibe Coding from npm: @structured-vibe-coding/cli (binary: sdd)

bash
npm install -g @structured-vibe-coding/cli
cd your-app
sdd setup
sdd go "Fix empty list crash" --no-agent

On a terminal, sdd setup walks the pieces. Press Enter to write three roles when you have no roles yet. sdd setup --yes --no-agent writes those roles without questions. A role is a job in the repo. A duty is the kind of work it does: the planner plans, the architect names the modules, and the builder builds the change pack. The mapping is which stages of the workflow you named belong to that duty. sdd go asks their questions one at a time. With SDD_ROLE_MODEL set, the role writes the note and the guide hands the next stage to the next role. You still decide.

What they are, why that split helps, and the setup for a software team: Roles and duties.

A named host is sdd setup --ai copilot, or sdd init --here --ai copilot when you want to pick the workflow yourself.

Full walkthrough with a paste-ready example: Start in 10 minutes.

Learning tip

Add --no-agent the first time. You learn the process without the AI window popping up. Drop the flag later when you want the agent to help.
